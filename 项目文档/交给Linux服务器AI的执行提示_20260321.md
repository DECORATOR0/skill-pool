# 交给Linux服务器AI的执行提示

请在 Linux 服务器上完成这个项目的代码同步、环境配置、数据迁移和基础验证。

## 目标

1. 拉取远端分支 `dev/linux-sync-20260321`
2. 用仓库根目录下的 `environment.skill-eval.yml` 创建 conda 环境
3. 不通过 git 传输 benchmark 大数据，改为从 Hugging Face 下载 `Sssunset/Earth-Bench`
4. 在 Linux 上重建软链接：`project_skills/benchmark -> ../benchmark/benchmark`
5. 复制并修改 Linux 本地配置
6. 先跑 smoke test，再跑 1 个 task 的最小训练验证

## 直接参考文件

- 主说明文件：
  `项目文档/Linux服务器迁移执行说明_20260321.md`
- 环境文件：
  `environment.skill-eval.yml`

## 执行要求

- 工作目录使用仓库外层根目录
- 不要把 `benchmark/`、`project_skills/benchmark/`、`project_skills/runs/` 提交回 git
- 如果发现 `question.json` 或 `model_results.csv` 缺失，再单独补齐，不要因此回退整个流程
- 优先保证 `project_skills.nlrl_skills.cli` 的双模式训练流程可运行

## 验收标准

至少完成下面两步并给出结果：

1. `python -m project_skills.agent.skill_eval.test_all_tools_smoke --output-dir project_skills/benchmark/out/linux_smoke`
2. `python -m project_skills.nlrl_skills.cli --config project_skills/configs/system.dualmode_mode1.linux.json train-tasks --start-index 0 --count 1 --run-name linux_smoke --reset-skill-library --reset-experience-buffer`

如果 mode1 通过，再继续准备 mode2。
