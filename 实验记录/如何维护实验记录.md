# 如何维护实验记录

`实验记录/实验总表.md` 不是手工慢慢补的，默认由脚本生成。

## 1. 更新命令

在仓库根目录执行：

```powershell
python project_skills/scripts/generate_experiment_table.py
```

默认行为：

- 扫描 `project_skills/runs/`
- 跳过 `_isolated`、`_launch_logs`、`temp`
- 自动生成 `实验记录/实验总表.md`

## 2. 表里会写什么

会生成两层表：

1. run 级总览
2. task 级逐条记录

每个 task 行默认会带：

- 日期
- run 名称
- task 目录
- 题号
- 阶段
- 状态
- 关键配置
- 轮数
- 结果
- 现象 / 分析摘要

## 3. 哪些情况要立刻更新

- 跑完一个新 run
- 清理或重命名了 run
- 用户要求解释某个 run，且你已经得出明确结论
- TODO 状态因为实验结果发生变化

## 4. 人工补充规则

脚本能提炼 JSON 里的已有字段，但它不会替你做真正的研究判断。

如果某个现象特别关键，除了更新总表，还应该同步到：

- `待办/进行中.md`
- `待办/已完成.md`
- `AI交互记录/`（仅限需要长期记住的用户约定）
