# 观察与假设

这份文件专门放“和 AI 讨论项目时冒出来的新观察、新想法、新假设”。

它和其它文档的分工是：

- `项目文档/`：已经稳定下来的说明
- `实验记录/实验总表.md`：已经发生过的 run 和结果
- `待办/`：已经决定要做的事
- `AI交互记录/`：需要长期记住的协作约定
- `实验记录/观察与假设.md`：还在思考中的判断、推测、现象解释、下一步实验想法

## 建议写法

每条尽量按下面 5 项写：

1. 时间
2. 触发来源
3. 观察
4. 假设 / 推断
5. 下一步怎么验证

---

## 模板

### [YYYY-MM-DD HH:MM] 标题

- 触发来源：
  - 例如某次 run、某个 task、某段和 AI 的讨论

- 观察：
  - 看到的现象是什么

- 假设 / 推断：
  - 你现在怀疑原因是什么

- 下一步验证：
  - 下一次实验要怎么验证

- 后续去向：
  - 如果验证成立，转进 `待办/进行中.md` 或 `项目文档/`
